# Resumes

Edit `preston-wallace-software-engineer.md` to update the resume linked from the homepage.

To create a version, copy that file to another Markdown filename in this directory, such as `robert-half-preston-wallace-ai-engineer.md`. Keep the required `title` and `description` frontmatter and edit the text. The next site build generates `/resume/robert-half-preston-wallace-ai-engineer/` automatically.

Git ignores these additional Markdown files. They are available to local builds, but a deployment built from the Git repository will not include them unless the files are supplied to that build separately.

Keep the same Markdown structure: name as H1, role and contact paragraphs, summary blockquote, skills paragraph, H2 sections, H3 roles/projects, and bullet lists. The horizontal rule separates the final languages and interests paragraphs.

All resume pages use `noindex` and are excluded from the sitemap. There is no resume listing. Only the original is linked from the homepage. Direct links are public and do not provide access control.

Use **Print / Save PDF** to print at Letter size (8.5 × 11 inches), 100% scale, with browser headers and footers disabled. The original content fits one page. Check print preview after editing, especially when adding text. The layout allows additional pages rather than hiding overflowing content.
